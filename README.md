# Noteflow

Offline-first, privacy-focused note-taking app. **Import files as a canvas, annotate, autosave with version history.** Built with Flutter — runs on Android phone, Android tablet, iOS, Web, and Desktop from one codebase.

> Status: MVP scaffold. Functional offline core (import → annotate → autosave → version history). Online sync and E2E encryption are staged for later milestones.

## Why Flutter

- One codebase → Android (phone + tablet) + iOS + Web + Desktop (your "web optional" is nearly free)
- Best-in-class free PDF annotation via `pdfrx` (Google PDFium engine)
- First-class Material 3 theming with warm paper palettes
- 100% free tooling (Flutter SDK, Android Studio, VS Code — all open source)

## Run it

1. Install Flutter: <https://docs.flutter.dev/get-started/install>
   - Android: install Android Studio + an emulator or connect a device (enable USB debugging)
2. Generate the platform folders (this repo is hand-written `lib/` only):

   ```sh
   cd noteflow
   flutter create . --platforms=android,ios,web --org com.yourname --project-name noteflow
   flutter pub get
   dart run build_runner build --delete-conflicting-outputs   # generates drift database code
   ```

3. Run:

   ```sh
   flutter run    # pick a connected device / emulator
   # or: flutter run -d chrome   (web)
   ```

> Note: `database.g.dart` is generated by drift. If it's missing, run the `build_runner` step above.

## Design system

Themes are generated from warm "paper" palettes (research-backed, see `theme/app_theme.dart`):

- **Light**: ivory `#FFFDF8` canvas, warm charcoal `#141414` text, sepia-brown accent `#825500`
- **Sepia**: parchment `#F8F1E3`, ink-blue `#3366CC` accent
- **Dark**: `#121212` canvas, off-white `#E1E1E1` text (no pure black/white — reduces OLED halation)
- **AMOLED**: true black `#000000` canvas

Material 3 dynamic color (Material You) can be enabled on Android 12+ later by swapping the schemes for `ColorScheme.fromSeed(seedColor: ...)` per theme — the token mapping in `AppTheme.build()` is already structured for it.

## Security model (designed, partially implemented)

Threat model: lost/stolen device, cloned backups. Not defending against rooted malware.

- MVP is offline-first, no account, no cloud — nothing leaves the device
- `SecurityService` provides AES-256-GCM encryption primitives + OS Keystore via `flutter_secure_storage`
- Planned: SQLCipher database, Argon2id KEK/DEK envelope, biometric unlock, encrypted Automerge sync (zero-knowledge server in Rust)
